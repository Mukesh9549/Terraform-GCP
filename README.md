# Terraform-GCP
Terraform GCP Practise
# Step 1: Clone the repo (if not already cloned)
git clone https://github.com/Mukesh9549/Terraform-GCP.git

# Step 2: Go into the project directory
cd Terraform-GCP

# Step 3: Fetch all remote branches
git fetch origin

# Step 4: Checkout the remote Practise branch (case-sensitive)
git checkout -b Practise origin/Practise

# Step 5: Make code changes (edit/add files as needed)

# Step 6: Stage all changes
git add .

# Step 7: Commit your changes
git commit -m "Updated Terraform code"

# (Optional - only if you get user identity error)
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

# Step 8: Push your changes to the Practise branch
git push


# for the Existing Code to push

1. Stage all changes (to track the modified files)
git add .

2. Commit the changes (with a meaningful message)
git commit -m " EX: Updated Terraform code "

3. Push the changes to the remote Practise branch
git push
